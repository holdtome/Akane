## 📌 功能清单
- 本项目是基于 Rust 构建的本地弹幕播放器，内置自研弹幕渲染层，弹幕绘制逻辑完全自主实现，不依赖第三方弹幕渲染库。项目预留弹幕源 API 接口，设计上支持自定义弹幕地址接入，后续计划逐步适配更多平台弹幕协议，拓展弹幕来源。播放器核心定位优先保障本地播放能力，断开网络环境下，可独立加载本地视频与本地弹幕文件，无需联网即可正常播放渲染弹幕。在兼顾离线隐私使用场景的同时，保留网络弹幕扩展潜力，兼顾性能、可定制性与扩展性，适合需要本地观影、自定义弹幕源的用户。
